# Católico Blindado - Landing Page

Esta é a estrutura da página da "Trilha da Blindagem". 
A página é construída com HTML estático e CSS (inline/styles no head), o que garante máxima velocidade e facilidade de implantação.

## 🚀 Como fazer o Deploy na Vercel

1. **Crie um Repositório no GitHub:**
   - Acesse o seu [GitHub](https://github.com/) e crie um novo repositório vazio.
   - Siga as instruções para fazer o "push" (envio) dos arquivos da sua máquina para o GitHub:
     ```bash
     git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
     git branch -M main
     git push -u origin main
     ```

2. **Conecte com a Vercel:**
   - Acesse a [Vercel](https://vercel.com/) e faça login (você pode usar a sua conta do GitHub).
   - Clique em **"Add New"** > **"Project"**.
   - Importe o repositório do GitHub que você acabou de criar.
   - Clique em **"Deploy"**. A Vercel vai reconhecer automaticamente o arquivo `index.html` e sua página estará online em poucos segundos.

## 📁 Estrutura de Arquivos

- `index.html`: Arquivo principal contendo todo o conteúdo, estruturação e estilos visuais da página (o seu arquivo `catolico-blindado-v5.html` anterior renomeado).

## ✏️ Edição

Para editar o site localmente, basta abrir o arquivo `index.html` no seu navegador de preferência e no seu editor de código (como o VS Code). Atualize a página no navegador para visualizar as mudanças.
